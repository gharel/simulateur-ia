Répondre ou agir

Une IA peut répondre dans la conversation. Elle peut aussi agir : faire une tâche en plusieurs étapes, sur tes fichiers. On parle alors d'un agent. Pour créer le tien : voir « L'Agent sur Mesure ».

Chat + Cowork Claude

Exemple chez Claude. Avant, il fallait choisir : Chat pour parler, Cowork pour lui confier une tâche sur tes fichiers. Les deux deviennent une seule appli : Claude.

Tu n'as plus à choisir. Tu écris ta demande. L'IA voit si elle doit répondre, ou agir en plusieurs étapes.

Et l'agent de code ?

Il reste à part. C'est l'outil pour créer ou modifier un logiciel, un site, une appli. Il lit le code, le change et le teste.

    Les risques de chaque outil

    Un ordre caché dans un e-mail ou une page web peut piéger l'IA (voir « Le Message Piégé »). Le danger grandit quand l'IA réunit trois ingrédients : tes données, un contenu venu de l'extérieur, et le droit d'agir seule.

    UsageRisque
    Tu écris toi-même ton texte–––Très faible
    Tu colles un e-mail ou un PDF reçu––Faible
    L'IA cherche sur le web pour toi––Faible
    Assistant branché sur ta boîte mail, en lecture seule–Moyen
    Agent qui lit tes e-mails et répond seulÉlevé
    Agent qui navigue sur le web avec tes comptes connectésÉlevé

    Un connecteur, ou un agent qui agit sur tes fichiers, peut ajouter et . Par défaut, l'IA te demande la permission avant d'agir. Un réglage lui permet de continuer sans demander : garde-le pour les tâches sans risque. Plus l'IA a de pouvoir, plus ce qu'elle lit compte.

    À retenir

    • Un bon prompt = le contexte + une action précise + l'objectif.
    • L'IA répond, ou elle agit comme un agent, selon ta demande. L'agent de code reste à part, pour créer des logiciels.
    • Projet = ton contexte et tes documents. Skill = ta méthode. Connecteur = un accès à tes autres outils.
    • Claude, ChatGPT… Chaque IA a ses propres noms, mais les outils se ressemblent.
