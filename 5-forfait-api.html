Les prix (modifiables)

Les prix changent souvent. Tu peux les corriger ici.

Prix API publics de septembre 2026 : Haiku 4.5 = 1 $ / 5 $, Sonnet 5.5 = 2 $ / 10 $, Opus 5.5 = 4 $ / 20 $. Choisir un modèle remplit ces cases. Le prix du forfait est un exemple : vérifie le tarif actuel.

Bloqué ou pas ?

Forfait

Le prix ne bouge pas.

Si tu utilises beaucoup, tu dois faire une pause. La limite revient après quelques heures.

API

Pas de pause obligatoire.

Mais la facture monte avec l'usage. On peut fixer un plafond de dépense.

À retenir

  • Forfait = prix fixe, mais une limite. Quand elle est atteinte, il faut attendre.
  • API = jamais de pause obligatoire, mais tu paies chaque token.
  • À chaque message, l'IA relit la conversation. Une longue conversation coûte donc plus cher.
